# Security Policy / 安全策略

[English](#english) · [简体中文](#简体中文)

## English

### Supported versions

Only the latest release receives security fixes. Pierlink updates itself, so please keep auto-update on.

### Reporting a vulnerability

Please **do not** open a public issue. Report it privately instead:

1. Go to the [Security tab](https://github.com/pierlink/Pierlink/security) of this repository.
2. Click **Report a vulnerability** and describe the issue, the affected version and how to reproduce it.

Never include real passwords, private keys or tokens in a report. You will get a reply as soon as possible, and the fix will be credited to you in the release notes if you wish.

## 简体中文

### 支持的版本

只有最新版本会修复安全问题。Pierlink 会自动更新，请保持自动更新开启。

### 报告漏洞

请**不要**公开提 Issue，改用私下报告：

1. 打开本仓库的 [Security 页面](https://github.com/pierlink/Pierlink/security)。
2. 点 **Report a vulnerability**，写明问题、受影响的版本和复现步骤。

报告里不要包含真实的密码、私钥或令牌。我们会尽快回复；如果你愿意，修复发布时会在更新说明里致谢。
