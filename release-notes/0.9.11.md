Pierlink 0.9.11

- 终端：
  - 服务器终端断开后（比如网络断了）点“重新连接”，回到断开前所在的目录；新开的终端照常从主目录开始。需要这台服务器开着命令预测（默认开）。
  - 在 tmux、screen 里用过 Claude Code、Codex，或者用过 vim、htop 之后，光标不会再一直不闪，闪不闪以设置为准。
  - 修了打字时输入法的组字框有时跑到屏幕左上角的问题（终端是在后台标签里打开的、切过去后光标没动过时会出现）。
  - 设置 → 终端 新加“PowerShell 提示音”（默认开）：关掉后，新开的 PowerShell 退格删到头、补全不到时不再“咚”一声。Pierlink 自己不发任何声音，这一声是 PowerShell 发的。
- AI 接入（MCP）：
  - 右上角的“AI 已连接”只在 AI 最近 5 分钟用过 Pierlink 时显示，关掉 AI 接入后也不再显示。以前 AI 客户端只要开着就一直显示，比如“已连接 · 55 分钟前”。
  - MCP 页不再跳动：查客户端加好没有时先占好位置，结果出来只换文字；换客户端、换入口时下面的内容不动；端口被占用、出错的提示写在端口下面那一行。
- 服务器桌面：
  - 没有桌面的服务器上，卡片上改成“安装桌面”：装和本机一样的 XFCE 桌面（桌面、面板、文件管理器、终端、中文字体）。浏览器不装，需要的话在桌面里自己装。
  - 装之前先检查：要下载、占用多少空间，磁盘还剩多少（不够就不让装，并说清差多少），内存和 CPU（配置低时提醒）。
  - 在桌面下面开出的终端里安装，要 sudo 密码时在那里输入；装完卡片自动回到“新建桌面”。没有管理员权限的账号会给出安装命令，也可以先用只有终端的精简桌面。
  - 不用管理员权限下载 TigerVNC 和精简桌面之前，也先检查家目录的空间。

Pierlink 0.9.11 (English)

- Terminal:
  - Reconnecting a server terminal after it was disconnected (for example when the network dropped) puts you back in the directory you were in. New terminals still start in the home directory. This needs command prediction on for that server (it is on by default).
  - After using Claude Code or Codex inside tmux or screen, or after vim or htop, the cursor no longer stays steady for good; your cursor blink setting decides.
  - Fixed the IME composition box sometimes appearing in the top-left corner of the screen (when the terminal had been opened in a background tab and the cursor hadn't moved since).
  - Settings > Terminal > PowerShell beep (on by default): turn it off and new PowerShell tabs stop beeping when there is nothing to delete or complete. Pierlink itself makes no sounds; that beep comes from PowerShell.
- AI access (MCP):
  - "AI connected" in the title bar now shows only when an AI used Pierlink in the last 5 minutes, and never while AI access is off. Before, it showed as long as an AI client was open, for example "connected, 55 minutes ago".
  - The MCP page no longer jumps: the client status keeps its place while checking and only its text changes, switching clients or entries leaves the rest in place, and port conflicts and errors show in the line under the port.
- Server desktop:
  - On a server without a desktop, the card now offers Install desktop: the same XFCE desktop as on a regular PC (desktop, panel, file manager, terminal, Chinese fonts). No browser is installed; install one inside the desktop if you need it.
  - Before installing, Pierlink checks how much will be downloaded and installed, how much disk space is left (it won't start if there isn't enough and says how much is missing), and the memory and CPUs (with a warning on small machines).
  - The install runs in a terminal that opens below the desktop, where you type the sudo password; when it finishes the card goes back to New desktop. Accounts without admin rights get the install command, or can use the terminal-only minimal desktop for now.
  - Downloads that need no admin rights (TigerVNC and the minimal desktop) check the free space in the home directory first.
