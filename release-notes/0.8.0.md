Pierlink 0.8.0

- 服务器桌面：在 Pierlink 里直接显示服务器的 VNC 桌面，和终端一样开在标签页里、能分屏。右键服务器“打开桌面”，或点服务器终端上方的桌面按钮。
  - 自动找到服务器上已有的 VNC 桌面（TigerVNC、TurboVNC、x11vnc 等），经 SSH 连接，服务器和本机都不开端口；
  - 要密码时输一次，可以记住（存在 Windows 凭据管理器）；
  - 画质（省流量 / 均衡 / 清晰）、适应窗口、远程分辨率跟随窗口、粘贴到远程、全屏；
  - 服务器上还没有 VNC 时，给出安装命令（推荐 TigerVNC + XFCE）。
- 终端：Shift+Enter 换行不执行（shell、PowerShell、Claude Code、Codex 等都能用）；程序里选中的文字能复制到本机剪贴板（OSC 52）；选中文字后右键不再丢掉选中；粘贴快捷键可选 Ctrl+V（默认）或 Ctrl+Shift+V；设置里还可以打开“选中后右键直接复制”和“没有选中时右键直接粘贴”。

Pierlink 0.8.0 (English)

- Server desktop: view a server's VNC desktop right inside Pierlink, in a tab that can be split like a terminal. Right-click a server and choose "Open desktop", or use the desktop button above a server terminal.
  - Finds existing VNC desktops on the server (TigerVNC, TurboVNC, x11vnc and others) and connects over SSH, with no ports opened on the server or this PC;
  - Enter the VNC password once and optionally remember it (stored in Windows Credential Manager);
  - Quality (low bandwidth / balanced / sharp), fit to window, match remote resolution to window, paste to remote, full screen;
  - If the server has no VNC yet, shows the install command (TigerVNC + XFCE recommended).
- Terminal: Shift+Enter inserts a new line without running it (in shells, PowerShell, Claude Code, Codex and more); text these programs copy reaches the local clipboard (OSC 52); right-clicking no longer clears the selection; the paste shortcut can be Ctrl+V (default) or Ctrl+Shift+V; Settings can also make right-click copy the selection, or paste when nothing is selected.
