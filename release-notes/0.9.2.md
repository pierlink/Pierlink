Pierlink 0.9.2

- 终端复制粘贴和常用终端一样：选中文字时 Ctrl+C 复制，没选中时照常中断程序；Ctrl+V、Ctrl+Shift+V 都能粘贴。
- “右键复制粘贴”合成一个开关：打开后，选中文字时右键复制，没选中时右键粘贴，不再弹菜单。
- 终端右键菜单改为：复制、粘贴、复制当前目录、在资源管理器中打开（本机终端）、左右分屏、上下分屏。在 Claude Code、vim 这类程序里右键交给程序，不会复制和粘贴一起发生。
- Claude Code、vim 等程序的复制（选中即复制）直接进 Windows 剪贴板，窗口不在前台时也行；tmux 里同样可用。GNU screen 会丢掉这类复制请求，在 screen 里请按住 Shift 拖选后用 Ctrl+C 复制，或改用 tmux。
- 点终端里的链接，用 Windows 的默认浏览器打开；拖选链接里的文字不再弹出确认框；确认框里可以复制链接。程序输出的超链接也一样。
- 从资源管理器把文件拖进本机终端，自动填上路径（有空格时加引号；WSL 里换成 /mnt/c/… 的写法）。
- 手机连接：配对成功、过期或点关闭后二维码自动收起；邀请码和链接可以一键复制；已配对的手机显示系统和浏览器、最近的 IP、配对日期，可以改名；手机上的配对页面重新设计，第一次打开快很多（要下载的从约 790 KB 减到约 110 KB）。
- 手机连接：监听地址每次点开都重新读取（刚连上 Tailscale 也能马上选到），只列 IPv4 地址；关掉 Tailscale 后也能正常关闭手机入口。
- 服务器桌面：和 Windows 之间直接用 Ctrl+C、Ctrl+V 复制粘贴；“输入剪贴板里的文字”把文字（包括中文）直接打进远程；Pierlink 新建的桌面里的终端支持 Ctrl+V 粘贴、选中即复制。
- 服务器桌面：全屏时鼠标指针和悬停提示不再看不见；弹到独立窗口后主窗口的窗格自动关掉，侧栏显示一个小图标，点它切到那个窗口，每台服务器只开一个；直接关掉独立窗口时先把远程分辨率改回去。
- AI 文件工具：读超大文件不再卡住、可以中途取消；换行符混用的文件也能按多行修改；文件被别的程序占用时说清原因；网络盘上的文件夹不能授权，添加时直接提示。
- 免 sudo 新建桌面时，只下载每组依赖里的第一个可用软件包，下载更少。
- 悬停提示在独立窗口里也正常显示，按钮文字变化后不再和系统自带的提示同时出现。

Pierlink 0.9.2 (English)

- Terminal copy and paste work as in common terminals: Ctrl+C copies selected text and interrupts the program otherwise; Ctrl+V and Ctrl+Shift+V both paste.
- One "right-click copy and paste" switch: when on, right-click copies selected text or pastes when nothing is selected, and the menu no longer opens.
- The terminal menu now has Copy, Paste, Copy current folder, Open in File Explorer (local terminals), Split left and right, and Split top and bottom. Inside programs such as Claude Code or vim, right-click goes to the program, so copy and paste never both happen.
- Text copied by Claude Code, vim and similar programs (copy on select) lands in the Windows clipboard, even when the window is not in front, and inside tmux too. GNU screen drops these copy requests; in screen, hold Shift while selecting and press Ctrl+C, or use tmux.
- Links in the terminal open in your default Windows browser; selecting text inside a link no longer opens the confirmation; the confirmation can copy the link. Links printed by programs work the same.
- Drag files from File Explorer into a local terminal to insert their paths (quoted when they contain spaces; written as /mnt/c/… in WSL).
- Phone access: the pairing QR code closes after pairing, on expiry or with Close; the code and link can be copied; paired phones show system and browser, last IP and pairing date, and can be renamed; the phone pairing page is redesigned and opens much faster the first time (about 110 KB to download instead of about 790 KB).
- Phone access: the address list reloads every time it opens (a fresh Tailscale address shows up right away) and lists IPv4 only; the entry can be turned off even after Tailscale is off.
- Server desktop: copy and paste between Windows and the desktop with plain Ctrl+C and Ctrl+V; "Type clipboard text" types the text (Chinese included) into the desktop; the terminal in desktops Pierlink creates supports Ctrl+V paste and copy on select.
- Server desktop: the mouse pointer and tooltips stay visible in full screen; after popping out to a separate window, the pane closes and the server list shows a small icon that switches to that window, one per server; closing the separate window restores the remote resolution first.
- AI file tools: reading huge files no longer stalls and can be cancelled; multi-line edits work in files with mixed line endings; a file in use by another program reports that clearly; folders on network drives can't be authorized and say so when added.
- Creating a desktop without sudo downloads only the first available package of each dependency group, so it downloads less.
- Tooltips work in separate windows too, and no longer show next to the system tooltip after a button's text changes.
