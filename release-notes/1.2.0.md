Pierlink 1.2.0

资源管理器右键菜单可以直接在 Pierlink 里打开终端；光标闪烁不再忽快忽慢，npm 安装时转圈也不再让光标来回跳。在程序里检查更新即可升级。

- 新增：在资源管理器里右键文件夹、文件夹空白处或磁盘，选“在 Pierlink 中打开”，就在 Pierlink 新开一个标签，用默认本机终端从这个目录开始；Pierlink 没开时会先打开。Windows 11 上这一项在“显示更多选项”里。不想要可以在“设置 → 终端 → 资源管理器右键菜单”关掉。
- 修复：本机 PowerShell、命令提示符、Git Bash 里跑 Codex 时，Shift+Enter、Ctrl+J 不能换行。现在按键原样交给 Windows，和 Windows Terminal 一样。
- 改进：从别的标签或页面切回来时，键盘焦点回到离开前的地方（终端或输入框），不用再点一下终端才能打字。
- 修复：Codex、Claude Code 这类程序隔一会儿重画一次输入行时，光标闪烁忽快忽慢、连闪两下，有时一直亮着。现在光标始终亮灭各 0.6 秒，只有打字时保持亮着。
- 修复：npm install（比如更新 Codex 时）这类程序转圈时，光标在转圈字符上和它后面来回跳、一直闪。终端现在用随安装包带的微软新版 ConPTY（和 Windows Terminal 用的同一份），程序输出什么就显示什么；经系统 OpenSSH 连的服务器上，bash 的括号粘贴、Claude Code 和 Codex 里的 Shift+Enter 换行也跟着能用了。万一新开的终端显示不对，可以在“设置 → 终端”打开“用 Windows 自带的终端引擎”退回原来的。

Pierlink 1.2.0 (English)

Open a terminal in Pierlink straight from File Explorer; the cursor now blinks at a steady pace, and no longer jumps around while npm shows its spinner. Update inside the app.

- New: right-click a folder, the empty space inside a folder or a drive in File Explorer and choose “Open in Pierlink” to open a new tab with your default local terminal in that folder; Pierlink starts first if it is not running. On Windows 11 the item is under “Show more options”. Turn it off in Settings > Terminal > Explorer context menu.
- Fixed: Shift+Enter and Ctrl+J did not insert a new line in Codex running in a local PowerShell, Command Prompt or Git Bash. Keys now reach Windows exactly as pressed, as in Windows Terminal.
- Improved: switching back to a tab or to the workspace puts the keyboard focus back where it was (the terminal or the input box), so you can type without clicking the terminal first.
- Fixed: when programs such as Codex or Claude Code redrew their input line every so often, the cursor blinked unevenly, sometimes twice in a row or not at all. It now always blinks on and off every 0.6 seconds and stays on while you type.
- Fixed: while programs such as npm install (for example when Codex updates itself) showed a spinner, the cursor kept jumping between the spinner and the cell after it. Terminals now use the newer Microsoft ConPTY shipped with the installer (the same one Windows Terminal uses), so program output is shown as is; on servers connected with system OpenSSH, bash bracketed paste and Shift+Enter for a new line in Claude Code and Codex now work too. If new terminals ever display incorrectly, turn on “Use the Windows built-in terminal engine” in Settings > Terminal to go back.
