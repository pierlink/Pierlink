Pierlink 1.2.15

手机上能发组合键了，新开的终端沿用当前目录，Antigravity 和 Gemini CLI 可以一键接入，还有一批终端和连接上的修正。在程序里检查更新即可升级。

- 手机：输入框里有字时，右边的按钮是“填入”，只把字写进终端、不回车；框里没字时是“发送”，按一下回车。
- 手机：键盘栏最左边的键盘按钮打开组合键面板，点 Ctrl、Alt、Shift 再点键，可以连成一组（比如 Ctrl+A 再按 d 退出 screen），马上发出，或存到键盘栏以后一点就发。
- 终端：点“+”新建、分屏时，新终端从当前本机终端所在的目录开始；标签右键菜单新增“复制标签”，同一种终端、同一个目录再开一个（服务器终端装了提示符钩子时同样沿用目录）。
- 终端：新开的终端和 AI 执行的命令用的是系统现在的环境变量。以前要重启 Pierlink 才认新加的环境变量和改过的 PATH。
- 终端：最小化再回来、最大化、点了标签栏和窗格标题栏上的按钮之后，键盘还在终端里，不用再点一下。
- 修复：往上翻过之后把标签并进分屏或改了窗口大小，Claude Code 重画完画面停在最上面、不跟着新输出走。
- 文件面板：新增“铺满窗格”按钮，面板临时盖住终端来整理文件，终端大小不变，还原后画面原样。
- AI 接入：一键添加支持 Antigravity（桌面端、IDE、命令行共用一份配置）和 Gemini CLI，这台电脑和服务器上都可以。
- AI 接入：可以给勾选的服务器各填一个工作目录。AI 列目标时能看到它，在这台服务器上执行命令、开终端时默认从这里开始。
- 连接：网络时通时断时不再每隔一两秒重新登录一次。连续断开后的重连间隔是 1、5、10、20、30、60 秒，连稳一分钟才从头算；服务器上的转发端口还被旧连接占着时至少隔 30 秒再试。以前短时间内的多次登录会被服务器的安全检测当成有人在试密码。

Pierlink 1.2.15 (English)

Key combos from the phone, new terminals start in the current directory, one-click setup for Antigravity and Gemini CLI, plus a batch of terminal and connection fixes. Update inside the app.

- Phone: when the input box has text, the button next to it says "Insert" and only types the text into the terminal without pressing Enter; when the box is empty it says "Send" and presses Enter.
- Phone: the keyboard button at the left of the key bar opens a key combo panel. Tap Ctrl, Alt or Shift and then a key, chain several into a sequence (Ctrl+A then d to detach from screen, for example), send it right away or save it to the key bar for one-tap use.
- Terminal: the "+" button and splits start the new terminal in the directory of the current local terminal. The tab context menu has a new "Duplicate tab" that opens the same kind of terminal in the same directory (server terminals too, when the prompt hook is installed).
- Terminal: new terminals and commands run by AI get the system's current environment variables. Previously newly added variables and PATH changes were not seen until Pierlink was restarted.
- Terminal: after minimizing and restoring, maximizing, or clicking buttons on the tab bar and pane title bar, the keyboard stays in the terminal without another click.
- Fixed: after scrolling up, merging a tab into a split or resizing the window left the view stuck at the top once Claude Code had redrawn, instead of following new output.
- Files: a new "Fill the pane" button lets the file panel temporarily cover the terminal while you manage files. The terminal keeps its size and looks the same when restored.
- AI access: one-click setup now supports Antigravity (its app, IDE and CLI share one configuration) and Gemini CLI, on this PC and on servers.
- AI access: each server you allow can have a working directory. The AI sees it when listing targets, and commands and terminals it opens on that server start there by default.
- Connections: on a flaky network Pierlink no longer logs in again every second or two. After repeated drops the reconnect intervals are 1, 5, 10, 20, 30 and 60 seconds, and the count only resets after a connection has been stable for a minute; when the forwarded port on the server is still held by the old connection, it waits at least 30 seconds before trying again. Many logins in a short time could be flagged by the server's security checks as password guessing.
