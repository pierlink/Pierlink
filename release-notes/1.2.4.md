Pierlink 1.2.4

同步任务只有个别文件过不去时不再显示“出错”，失败的文件和原因看得到了。在程序里检查更新即可升级。

- 改进：同步任务其他文件都已同步、只有个别文件过不去时，显示黄色的“部分未同步”（“其他文件已同步 · N 个文件无法同步”），不再算作“出错”；失败列表里每个文件后面写明原因，比如“没有权限”，完整原文在鼠标悬停提示里。托盘菜单里会写“N 个部分未同步”，不按“有问题”算。
- 改进：新建同步任务的默认排除规则加上 Python 测试和检查工具的缓存目录（.pytest_cache、.mypy_cache、.ruff_cache）。已有的任务不变，需要的话在“编辑任务”里加。
- 修复：同步任务最近事件多的时候，“N 个文件同步失败”和冲突文件的框被压成一条细线，看不到里面的文件。

Pierlink 1.2.4 (English)

A sync task with only a few files that can't sync no longer shows as an error, and the failed files and reasons can be seen. Update inside the app.

- Improved: when everything else in a sync task is up to date and only a few files can't sync, the task shows a yellow "Partly synced" ("Everything else is up to date · N files can't sync") instead of an error; each failed file shows a short reason such as "No permission", with the full text on hover. The tray menu says how many tasks are partly synced instead of counting them as problems.
- Improved: the default exclusion rules for new sync tasks now include Python test and lint caches (.pytest_cache, .mypy_cache, .ruff_cache). Existing tasks are unchanged; add them in Edit task if needed.
- Fixed: when a sync task had many recent events, the "N files failed to sync" and conflict boxes were squeezed into a thin line and their files could not be seen.
