Pierlink 0.9.8

- 连接服务器时只有一张连接卡片：点连接后标签马上打开，卡片从核对指纹一直显示到出现提示符，进度连续推进。分成“连接、验证主机、登录、启动终端”四步，连好后填满淡出；指纹确认、连不上时重试、取消都在这张卡片上。
- 手机端大改，方便在手机上和服务器里的 Claude Code 对话：
  - 终端页全屏、带颜色；往上翻时不再被拉回底部，翻到顶自动多读一些；字号三档，可开关自动换行，能长按选中复制。
  - “按手机宽度显示”：看终端时把电脑上的终端临时改成手机的宽度，Claude Code 按手机宽度排版；离开、锁屏一会儿或电脑上有人打字时恢复。
  - Claude Code 的编号选项和 (y/n) 直接变成大按钮；方向键之后按回车不再要求二次确认；按键栏加了 Shift+Tab、←、→、退格。
  - 多行输入：换行不会把消息拆开发出去；长按“发送”只输入不回车。
  - 能从相册或相机发图片给 Claude Code（显示成 [Image #1]）。
  - AI 等你确认时标题上显示个数，终端页顶上有“去确认”；安卓手机开着页面时还会振动。
  - 终端列表显示是否在运行、当前目录和最后一行，电脑上开关终端时自动刷新；能加到主屏幕；可以在手机上退出。
- AI 接入（MCP）：
  - 写文件时自动创建缺少的文件夹；新增建文件夹、删除、重命名（删除文件夹总是要你确认）。只开服务器入口、不许在 Windows 上执行命令时，服务器上的 AI 也能整理 Windows 上的项目文件。
  - MCP 页能看到 AI 开的后台任务（如 npm run dev），可以单独停掉；“全部停止”随时能点。
  - 确认框里能看到要替换的旧文字和新文字、要写入的前几行；英文界面的确认框不再夹着中文。
  - 危险命令清单补上 git clean、git checkout --、git restore、curl | sh、iex、改 HKLM 注册表、建计划任务、强制结束进程、docker prune 等。
  - 命令的工作目录必须是绝对路径，不会再跑到 Pierlink 自己的目录里；命令太长时直接告诉 AI 上限。
  - 搜索更快，结果按文件分组、更短；AI 读图片文件时能直接看到图片；终端按键支持 F1–F12、Alt+字母等。
  - 第一次打开 AI 接入时顺带打开本机入口。

Pierlink 0.9.8 (English)

- Connecting to a server now uses a single card: the tab opens right away and the card stays from the host key check until the shell prompt appears, with progress that moves continuously. It has four steps (Connect, Verify host, Sign in, Start shell) and fills up and fades out when done; confirming a host key, retrying a failed connection and cancelling all happen on the same card.
- A much better phone page for talking to Claude Code on your servers:
  - The terminal page is full screen and in color. It no longer jumps back to the bottom while you scroll up, and loads more lines when you reach the top. It has three font sizes and optional line wrapping, and you can long-press to select and copy text.
  - "Fit to phone": while you watch a terminal, it is temporarily resized to the phone's width so Claude Code lays out for the phone. The size is restored when you leave, after the phone has been locked for a while, or as soon as someone types on the PC.
  - Claude Code's numbered options and (y/n) prompts become big buttons. Enter after arrow keys no longer asks for confirmation, and the key bar has Shift+Tab, ←, → and Backspace.
  - Multi-line input: line breaks no longer split your message into several sends. Long-press Send to type without Enter.
  - Send photos or screenshots to Claude Code from your phone (shown as [Image #1]).
  - When AI is waiting for your confirmation, the title shows a count and the terminal page shows a banner; Android phones also vibrate while the page is open.
  - The terminal list shows whether a program is running, the current folder and the last line, and refreshes when terminals open or close on the PC. You can add the page to your home screen and sign out on the phone.
- AI access (MCP):
  - Writing a file creates missing folders, and new tools create folders, delete and rename (deleting a folder always asks you). With only a server entry and no command access on Windows, the AI on your server can still organize the project files on Windows.
  - The MCP page lists background tasks the AI started (such as npm run dev) and can stop each one; "Stop all" is always available.
  - Confirmation dialogs show the old and new text of an edit and the first lines of a write, and no longer mix in Chinese in the English interface.
  - The dangerous-command list now covers git clean, git checkout --, git restore, curl | sh, iex, HKLM registry changes, scheduled tasks, forced process kills, docker prune and more.
  - Command working folders must be absolute paths, so commands no longer run in Pierlink's own folder; a command that is too long tells the AI the limit.
  - Search is faster and its results are grouped by file and shorter; the AI can see image files it reads; terminal keys include F1–F12 and Alt+letter.
  - Turning on AI access for the first time also turns on the local entry.
