Pierlink 1.2.12

私钥导入后由 Pierlink 加密保存、登录时从列表里选；服务器上的文件可以一键下载到固定的下载文件夹，标题栏“传输”里能换这个文件夹，也能直接打开它；AI 开的终端不再把你正在看的终端切走。在程序里检查更新即可升级。

- 新增：文件面板里右键服务器上的文件或文件夹，多了“下载”：直接下到下载文件夹（默认是系统“下载”文件夹里的 Pierlink），不用每次选位置；“下载到…”照旧可以选别的地方。
- 新增：标题栏“传输”面板顶部显示下载文件夹，旁边两个按钮：换一个文件夹、在资源管理器里打开。
- 新增：私钥改成导入后由 Pierlink 加密保存（设置 → 私钥），服务器的“指定私钥”从列表里选，不用再填文件路径，原文件不动；私钥有密码的可以保存密码，连接时自动填。支持 OpenSSH、PEM、.ppk 格式。以前按路径用的私钥照常能用，编辑服务器时一点就能导入。
- 改进：服务器入口（AI 接入）断网重连时，如果原来的端口被自己上一次没断干净的连接占着，现在会直接结束那条旧连接、按原端口马上连回来，不用再等十几分钟或换端口（用内置 SSH 的 Linux 服务器）。
- 改进：AI 经 Pierlink 打开的终端在后台新开标签，不再切过去，你正在看的终端不受打扰；点标签上带“AI”标记的那个就能看，它等你输密码时标签上会亮提醒点。
- 修复：Pierlink 装在带中文的文件夹里时（比如中文用户名），用系统 OpenSSH 连接的服务器填不进保存的密码和私钥密码。

Pierlink 1.2.12 (English)

Private keys are imported and stored encrypted, then picked from a list; server files can go straight to a fixed download folder, and the Transfers panel in the title bar lets you change that folder or open it; terminals opened by an AI no longer pull you away from the one you're watching. Update inside the app.

- New: Right-click files or folders on a server and choose Download to save them to the download folder (by default a Pierlink folder inside your Downloads) without picking a place each time; Download to… still lets you choose another place.
- New: The top of the Transfers panel in the title bar shows the download folder, with buttons to change it and to open it in File Explorer.
- New: Private keys are now imported and stored encrypted by Pierlink (Settings > Private keys); servers pick their key from that list instead of a file path; the original file is left as it is. Keys with a passphrase can save it so it's filled in when connecting. OpenSSH, PEM and .ppk formats work. Keys used by path keep working, and editing such a server imports the key in one click.
- Improved: When an AI access entry on a server reconnects after a network drop and its old, half-dead connection still holds the port, Pierlink now ends that old connection and reconnects on the same port right away instead of waiting 15 minutes or switching ports (Linux servers using built-in SSH).
- Improved: Terminals that an AI opens through Pierlink open in a background tab instead of taking over the view, so the terminal you're watching stays put; click the tab marked AI to look, and the tab lights up when it waits for your password.
- Fixed: When Pierlink lives in a folder with non-ASCII characters (such as a Chinese user name), servers using system OpenSSH couldn't get saved passwords or key passphrases filled in.
