Pierlink 0.9.6

- 远程桌面的剪贴板改成自动同步：在 Windows 上复制的文字会自动发到远程，远程里直接右键粘贴也能用（以前要先在画面里按一次 Ctrl+V）。从远程复制过来的文字不会再发回去，远程里复制的文件、图片不会被冲掉。去掉了工具栏上的“输入剪贴板里的文字”按钮。和其他远程桌面软件一样：连着桌面、Pierlink 在前台时，Windows 上复制的文字（包括密码）都会到远程的剪贴板。
- 终端光标：竖线光标加粗；Windows 关了“动画效果”时，光标也照常闪烁（不想闪可在 设置 → 终端 里关掉）。
- AI 接入：界面上“已连接 N 个 AI”会自己更新，服务器上的 AI 退出或 5 分钟没动静就不再算在内（以前要等半小时）。AI 读终端更可靠：输出里有没结束的控制序列（比如 cat 了一个二进制文件）时，后面的提示符照样读得到；输出恰好在换行处分块时，两行不再粘在一起。
- 命令预测：Windows 服务器、配置了 RemoteCommand 的服务器上，很短的正常会话不再被误判成“钩子不兼容”而自动关掉预测。本机 Git Bash 的 .bashrc 导出了 PROMPT_COMMAND 时，嵌套的 bash 不再在每个提示符报“command not found”。多行命令的续行上不显示预测；清除命令记录时，旧记录不会回来。

Pierlink 0.9.6 (English)

- Remote desktop clipboard now syncs automatically: text you copy on Windows is sent to the remote desktop, so right-click → Paste works there directly (you used to press Ctrl+V in the view first). Text that came from the remote is not sent back, so files and images copied on the remote are not replaced. The "Type clipboard text" toolbar button is gone. As in other remote desktop apps, while a desktop is connected and Pierlink is in front, any text you copy on Windows (passwords included) reaches the remote clipboard.
- Terminal cursor: the bar cursor is thicker, and it blinks even when Windows animation effects are turned off (turn blinking off in Settings → Terminal).
- AI access: "N AIs connected" now updates by itself; an AI on a server stops counting once it exits or has been idle for 5 minutes (this used to take half an hour). Reading the terminal is more reliable: a prompt after an unterminated control sequence (for example after cat-ing a binary file) can still be read, and two lines no longer run together when output is split at a line break.
- Command prediction: on Windows servers and servers with a RemoteCommand, a short normal session is no longer mistaken for an incompatible hook that turns prediction off. In local Git Bash, when .bashrc exports PROMPT_COMMAND, nested bash shells no longer print "command not found" at every prompt. No suggestions on the continuation lines of a multi-line command; clearing the history no longer brings old commands back.
