Pierlink 0.9.3

- 英文界面里，错误提示的具体原因也显示英文了（以前很多原因是中文，混在英文句子里）。“命令提示符”的名字、提示里的冒号和分号也跟着界面语言变。Windows 自己报的错误仍跟随系统语言。
- 本机 PowerShell、命令提示符里用过 Shift+Enter、Ctrl+Enter 或 Ctrl+J（加一行）之后，Esc 和 Ctrl+C 不再失灵：以前 Esc 清不掉输入行，Ctrl+C 会变成一个 ^C 字符，要按回车才恢复；在里面运行的 wsl、ssh 里的 vim 按 Esc 也会慢一拍。
- 服务器桌面：设置里新增“在独立窗口打开”。打开后，“打开桌面”直接弹出独立窗口，不用先在主窗口打开再转过去。
- 服务器桌面：断开重连后按 Ctrl+V，同样的文字也能再粘贴过去（以前会被当成已经发过而跳过）。

Pierlink 0.9.3 (English)

- In the English interface, the specific reason in error messages is now in English too (many reasons used to be Chinese inside English sentences). The Command Prompt name and the punctuation in combined messages follow the interface language as well. Errors reported by Windows itself still follow the system language.
- In local PowerShell and Command Prompt, Esc and Ctrl+C keep working after Shift+Enter, Ctrl+Enter or Ctrl+J (new line): Esc used to leave the input line as it was and Ctrl+C typed a ^C character until you pressed Enter; Esc in vim inside wsl or ssh in that window lagged one key behind.
- Server desktop: new setting "Open in a separate window". When on, Open desktop goes straight to a separate window instead of opening in the main window first.
- Server desktop: after reconnecting, Ctrl+V pastes the same text again (it used to be skipped as already sent).
