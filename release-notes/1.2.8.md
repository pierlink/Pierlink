Pierlink 1.2.8

安装桌面在用系统 OpenSSH 连接的服务器上也能自动运行了，卡片会照实说终端在等什么；AI 能看到 Pierlink 的基本情况，排查问题更快。在程序里检查更新即可升级。

- 修复：服务器用系统 OpenSSH 连接时，点“开始安装”打开的终端不会自动输入安装命令。现在看到 shell 提示符就自动输入（在问密码、验证码时不输）；一分钟都没等到就请你点“复制命令”自己粘贴。
- 改进：安装桌面的卡片照实说终端在等什么：等你输入 sudo 密码（输入时不显示字符）、服务器正在自动更新等它结束、需要你自己粘贴命令；apt 真的开始了才显示“正在更新软件源”。卡片上终端最后一行显示完整的提示符。
- 改进：安装桌面的确认框里，服务器用系统 OpenSSH 连接时会提示，并可以一键换成内置 SSH。
- 新增：AI 可以用 pierlink_status 查看 Pierlink 的基本情况：版本、各服务器的名字和连接方式、是否在线、打开着的终端、桌面、同步任务和 AI 接入入口的状态。不包含地址、用户名、密码、密钥和令牌。

Pierlink 1.2.8 (English)

Desktop install now runs on servers that connect with system OpenSSH, and its card says what the terminal is waiting for; AI can see Pierlink's basic status, so problems get sorted out faster. Update inside the app.

- Fixed: On servers that connect with system OpenSSH, the terminal opened by Start install never typed the install command. It's now typed once a shell prompt appears (never at a password or code prompt); if no prompt shows up within a minute, you're asked to copy the command and paste it yourself.
- Improved: The desktop install card says what the terminal is waiting for: your sudo password (nothing shows while you type), automatic updates on the server to finish, or you pasting the command; "Updating package lists" appears only once apt really starts. The terminal's last line on the card shows the whole prompt.
- Improved: The desktop install dialog points out servers that connect with system OpenSSH and switches them to the built-in SSH in one click.
- New: AI can use pierlink_status to see Pierlink's basic status: version, each server's name and connection method, whether it's online, open terminals, desktops, sync tasks and AI access entries. No addresses, user names, passwords, keys or tokens.
