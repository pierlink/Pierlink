Pierlink 0.9.5

- 终端命令预测：在服务器的 bash、zsh 和本机 Git Bash 里输入时，光标后面用浅色显示在这台服务器上用过、以当前输入开头的命令（同一目录下用过的优先，执行失败的不出），按 → 补全整条，Ctrl+→ 补一个词。程序运行中、等密码时、tmux 和嵌套的 shell 里不显示；fish、zsh-autosuggestions、ble.sh、PowerShell 自带预测，不重复显示。
- 命令记录只存在这台电脑上（每台服务器最多 5000 条，保留 180 天），不随配置导出；像是带密码、令牌的命令不记。设置 → 终端 里可以关闭预测、清除记录。
- 开着预测时，连接服务器会带上提示符钩子，服务器的欢迎信息（motd）和 “Last login” 不再显示。想看它们的服务器，在服务器右键菜单里点“关闭命令预测”，连接就和以前完全一样。少数服务器（如 Windows 的 OpenSSH 服务器、受限 shell）带钩子会连上就退出，终端里会提示这样关掉。
- 服务器终端的工具栏新增“连接 / 断开”按钮：连着时点它断开，断开时点它连接。
- 终端断开、断网或程序退出后，原来的内容留在终端里，最下面写一行说明，如“连接已断开，按 Enter 重新连接”（以前整块提示盖住内容）。登录失败、没能打开时仍显示提示块。重新连接时照旧清屏。

Pierlink 0.9.5 (English)

- Command prediction: as you type in bash or zsh on a server, or in local Git Bash, commands you have run on that server that start with what you typed appear in gray after the cursor (ones used in the same directory first; failed ones are skipped). Press → to accept the whole command, Ctrl+→ to accept one word. Nothing is shown while a program is running, at password prompts, or inside tmux and nested shells; shells with their own suggestions (fish, zsh-autosuggestions, ble.sh, PowerShell) are left alone.
- Command history stays on this computer (up to 5000 commands per server, kept 180 days) and is not included in exported profiles; commands that look like they contain passwords or tokens are not recorded. Turn prediction off or clear the history in Settings → Terminal.
- With prediction on, Pierlink logs in to servers with a prompt hook, so the server's welcome message (motd) and "Last login" line no longer appear. To see them on a server, choose "Turn off command prediction" in its right-click menu; the connection is then exactly as before. A few servers (such as Windows OpenSSH servers or restricted shells) exit right after connecting with the hook; the terminal then suggests turning it off this way.
- Server terminals have a Connect / Disconnect button in the toolbar: click it to disconnect while connected, or to connect while disconnected.
- When a terminal is disconnected, loses its connection or its program exits, the content stays and one line at the bottom says what happened, such as "Connection lost. Press Enter to reconnect." (a panel used to cover the content). Login failures and open errors still show the panel. Reconnecting clears the terminal as before.
