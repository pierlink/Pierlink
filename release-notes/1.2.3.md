Pierlink 1.2.3

服务器上的 AI 操作 Windows 上的 Codex 时，Codex 一提问 AI 就能知道。在程序里检查更新即可升级。

- 改进：经 MCP 操作终端的 AI 在等输出时，终端里的程序一响铃或发通知就立即返回，不用干等到超时。Codex 向你提问、要批准、做完一轮时默认会响铃（你没盯着那个终端时），不用改 Codex 的任何设置。Claude Code 默认不发通知，AI 会按“输出停下多久”来判断它在等回答。
- 修复：Windows 上的 Codex 在 AI 打开的终端里一直以为有人在看，提问时不响铃。现在程序进全屏时，Pierlink 如实告诉它当前有没有人在看。
- 新增：MCP 发送按键支持 Shift+方向键（Codex 里回答提问要按 Shift+←）。
- 改进：MCP 页“AI 装在服务器上”只列 Claude Code 和 Codex。

Pierlink 1.2.3 (English)

When an AI on a server drives Codex on Windows, it now learns right away when Codex asks something. Update inside the app.

- Improved: when an AI waits for terminal output over MCP, the wait now returns as soon as the program rings the bell or sends a notification, instead of waiting until the timeout. Codex rings by default when it asks you a question, needs approval or finishes a turn (while you are not looking at that terminal); no Codex settings need changing. Claude Code sends no notifications by default, so the AI judges from how long the output has been quiet.
- Fixed: Codex on Windows assumed someone was watching an AI-opened terminal and did not ring when it asked a question. Pierlink now reports whether the terminal really has focus when a program switches to full screen.
- New: MCP key presses support Shift+arrow keys (Codex uses Shift+Left to answer a question).
- Improved: the MCP page lists only Claude Code and Codex for an AI installed on a server.
