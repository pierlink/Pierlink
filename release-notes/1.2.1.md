Pierlink 1.2.1

同步任务里直接列出失败的个数和文件；AI 发给 Codex 的消息不再停在输入框里；文件栏可以一键复制当前路径。在程序里检查更新即可升级。

- 改进：同步任务有文件同步失败时，任务里写明失败的个数，下面只列出失败的文件，鼠标停在文件上显示原因。正在同步时即使有个别文件失败，任务也显示在“同步中”；同步停下来、只剩失败的文件时才归到“出错”。
- 修复：AI 经 MCP 给终端发一句以换行结尾的话时，Codex 只把文字填进输入框、没有发送（它把一下子到达的文字当成粘贴，紧跟着的回车只算换行）。现在文字写完隔 0.5 秒再按回车，手机上点“发送”也一样。
- 新增：“设置 → 终端 → 响铃提醒”。Codex 等程序响铃时，标签上的提醒点和任务栏按钮闪烁现在可以只留提醒点，或者都关掉。
- 新增：文件栏的路径后面加了复制按钮，一点就复制当前目录的完整路径（和服务器地址后面的复制按钮一样）。
- 改进：MCP 页“AI 装在服务器上”的服务器列表写明是哪台服务器上的 AI 还能操作这些服务器，并说明勾上后它能经 Pierlink 执行命令、读写文件（以前只写“可以操作的其他服务器”，看不出意思）。

Pierlink 1.2.1 (English)

Sync tasks now show how many files failed and which ones; messages an AI sends to Codex no longer stop in its input box; the files panel can copy the current path in one click. Update inside the app.

- Improved: when files fail to sync, the task now shows how many failed and lists just the files; hover over a file to see why. A task that is still syncing stays under “Syncing” even when a few files fail, and moves to errors only once syncing stops with failures left.
- Fixed: when an AI sent a line ending in a newline to a terminal over MCP, Codex only filled its input box and did not send it (it treats text that arrives all at once as a paste, and an Enter right after it as a new line). Enter now follows the text after 0.5 seconds; Send on the phone works the same way.
- New: Settings > Terminal > Bell alerts. When programs such as Codex ring the bell, you can now keep just the dot on the tab or turn off both the dot and the taskbar flash.
- New: a copy button right after the path in the files panel copies the current folder's full path in one click, like the one next to a server's address.
- Improved: on the MCP page, the server list for an AI installed on a server now names that server and says that on the servers you check, the AI can run commands and read and write files through Pierlink (it used to say only “Other servers it can use”).
