Pierlink 1.2.7

几台电脑同时开着 Pierlink 时，服务器上的 AI 会操作你正在用的那台，确认框也弹在你面前；也可以固定一台。AI 接入也更安全了。在程序里检查更新即可升级（几台电脑都要升级）。

- 新增：几台电脑接入同一台服务器时，后开的那台自动换一个端口接入，不再提示端口被占用。AI 的命令、文件、终端操作和确认框会转到你正在用的那台电脑：按 AI 所在的 Pierlink 终端判断（screen、tmux 里也认得出），认不出时看哪台最近有键盘鼠标操作。
- 新增：MCP 页可以选“AI 操作哪台电脑”：自动，或固定一台。固定的那台不在线时，AI 会收到提示，不会改到别的电脑；标题栏会提示固定了哪台，点开可以取消。
- 新增：先开的那台关掉后，另一台一分钟内接过端口，服务器上的 AI 客户端不用重新添加。
- 新增：AI 能做的事更多：在终端里整段粘贴、发 Shift+Enter 等换行键和更多快捷键、把图片发给服务器上的 AI 终端；复制文件和文件夹、写二进制文件、在 Windows 和服务器之间传文件、用默认程序打开文件或网址、一次读多个文件、一次改多处。要确认的操作照样弹确认框。
- 改进：操作记录里写明转给了哪台电脑、由哪台电脑转来。
- 改进：AI 写入 SSH、Git、shell 的配置（.ssh 下的文件、.git/hooks、.git/config、.gitconfig、.bashrc 等）和 .dll 文件时，也要你点允许。这些文件会被别的程序当作命令执行。
- 改进：Pierlink 自己的数据文件夹和安装文件夹，就算在授权给 AI 的文件夹里，AI 也读写不了；设置里也不能把它们授权给 AI。
- 改进：点“安装更新”时，会再核对一次下载好的安装包的签名；不对就删掉，请你重新下载。
- 修复：更新说明里的文字能选中、复制，也能用键盘翻页了，不会再被底部“可以更新了”的提示挡住；更新说明里可以直接点“下载更新”。选中文字后右键可以复制。

Pierlink 1.2.7 (English)

When several computers run Pierlink, the AI on a server works on the one you're using, and approvals pop up in front of you; you can also pin one. AI access is safer too. Update inside the app (update every computer).

- New: When several computers connect to the same server, the later one joins through a free port instead of reporting the port as busy. The AI's commands, file and terminal operations and approvals go to the computer you're using: Pierlink recognizes the terminal the AI runs in (inside screen and tmux too) and otherwise picks the computer with the most recent keyboard or mouse input.
- New: On the MCP page, choose which computer the AI works on: automatic, or a fixed one. If the pinned computer is offline, the AI is told so and nothing moves to another computer; the title bar shows which one is pinned, and you can unpin from there.
- New: When the first computer closes, another one takes over its port within a minute, so the AI clients on the server don't need to be added again.
- New: The AI can do more: paste text into a terminal in one piece, send Shift+Enter and other newline keys and more shortcuts, send images to an AI terminal on a server; copy files and folders, write binary files, move files between Windows and a server, open files or links with the default program, read several files at once, and make several edits in one go. Operations that need your approval still ask.
- Improved: The activity log shows which computer a call was sent to or came from.
- Improved: AI writes to SSH, Git and shell configuration (files under .ssh, .git/hooks, .git/config, .gitconfig, .bashrc and the like) and to .dll files now need your approval. Other programs run these files as commands.
- Improved: Pierlink's own data and install folders are off limits to AI even inside a folder you allowed, and Settings won't let you allow them.
- Improved: Install update checks the downloaded installer's signature again; if it doesn't match, the installer is removed and you download it again.
- Fixed: Text in the update notes can be selected, copied and scrolled with the keyboard, and the "update available" bar no longer covers it; you can start the download right from the notes. Right-click selected text to copy it.
