Pierlink 1.0.0

Pierlink（栈桥）第一个正式版：Windows 上的多服务器远程开发工作台，终端、文件同步、AI 接入，一个窗口管好所有服务器。从 0.9.x 在程序里检查更新即可升级，服务器、设置和同步任务都保留。和 0.9.12 相比：终端光标闪得更稳、稍慢一点；安装桌面的确认框主按钮改成“开始安装”，独立窗口里打开的桌面也能一键安装；安装时桌面卡片上显示进度（更新软件源、下载第几个包、安装百分比、终端最后一行、已用时间），出错时直接显示报错那行。

- 终端：服务器和本机终端多标签、分屏；切换页面后终端保持运行；广播输入、命令片段；Shift+Enter 换行；Claude Code、vim 里复制的内容直接进 Windows 剪贴板；命令预测（服务器 bash、zsh 和本机 Git Bash）；截图按 Ctrl+V 直接粘贴给服务器上的 Claude Code；断开、断网后内容保留，按 Enter 重连。
- 连接：内置 SSH（老服务器也能连），或按 `~/.ssh/config` 用系统 OpenSSH；可以走 HTTP、SOCKS5 代理；端口转发断线自动恢复；文件面板，窗格之间拖动传文件。
- 文件同步：基于 Syncthing，经 SSH 隧道，不开端口、服务器上不需要 root；首次同步前预览，冲突对比再选，删除和覆盖的文件可以找回。
- AI 接入（MCP）：Windows 不用装 Claude Code，服务器上的 AI 就能读写、按行修改、搜索你允许的 Windows 文件夹，在 Windows 上编译运行；危险操作要你确认，每一步都有记录，标题栏随时能看到 AI 在不在操作、一键全部停止；一键添加到 Claude Code、Codex、Cursor、Gemini CLI。
- 服务器桌面：在标签页里显示服务器的 VNC 桌面；没有桌面时先检查磁盘和配置，再一键安装 XFCE 桌面（文件管理器、终端都有）；剪贴板和 Windows 自动同步；能在独立窗口打开。
- 手机连接：不在电脑前时，用手机浏览器和服务器上的 Claude Code 对话（按手机宽度显示、选项变成按钮、能发图片），回答 AI 的确认、看服务器状态，深浅色跟随电脑；经 Tailscale 或局域网，没有中转服务。

Pierlink 1.0.0 (English)

The first stable release of Pierlink, a multi-server remote development workbench for Windows: terminals, file sync and AI access for all your servers in one window. Update from 0.9.x inside the app; your servers, settings and sync tasks are kept. Compared with 0.9.12: the terminal cursor blinks steadily and a little slower; the install-desktop dialog's main button now says Start install, and a desktop opened in its own window can be installed in one click too; while installing, the desktop card shows the progress (updating package lists, which package is downloading, install percentage, the terminal's last line and the time so far) and shows the error line if it fails.

- Terminals: tabs and split panes for server and local terminals that keep running when you switch pages; broadcast input and command snippets; Shift+Enter for a new line; text copied in Claude Code or vim lands in the Windows clipboard; command prediction (bash and zsh on servers, local Git Bash); paste a screenshot into Claude Code on a server with Ctrl+V; after a disconnect the content stays and Enter reconnects.
- Connections: built-in SSH (old servers too) or system OpenSSH with your `~/.ssh/config`; HTTP and SOCKS5 proxies; port forwards that recover after a drop; a file panel where you drag files between panes.
- File sync: built on Syncthing over an SSH tunnel, with no open ports and no root on the server; a preview before the first sync, side-by-side conflict resolution, and deleted or overwritten files you can restore.
- AI access (MCP): without installing Claude Code on Windows, an AI on your server can read, edit line by line and search the Windows folders you allow, and build and run on Windows; risky actions need your approval, every step is logged, and the title bar shows when an AI is working with a one-click stop; one-click setup for Claude Code, Codex, Cursor and Gemini CLI.
- Server desktop: the server's VNC desktop in a tab; on a server without one, Pierlink checks disk space and memory and then installs an XFCE desktop (with a file manager and terminal) in one click; the clipboard syncs with Windows; it can open in its own window.
- Phone access: away from your computer, talk to Claude Code on your servers from your phone's browser (laid out for the phone's width, options as buttons, photos you can send), answer AI approvals and check servers, with the PC's dark or light theme, over Tailscale or your LAN with no relay service.
