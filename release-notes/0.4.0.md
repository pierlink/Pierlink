Pierlink 0.4.0

- 内置 SSH：连接一台服务器只登录一次，终端、文件面板、同步、端口转发、资源概览共用这次登录；要手机验证码的服务器也能用全部功能。
- 终端更顺：服务器输出直接显示，vim、tmux 的鼠标和按键更准，调窗口大小时内容不乱。
- 服务器设置里新增“连接方式”：内置 SSH（默认）或系统 OpenSSH（按 ~/.ssh/config 连接）。从 ssh config 导入的服务器保持原来的方式，可以在它的设置里一键检查并转换成内置 SSH（地址、用户、密钥一起抄过来；带跳板 ProxyJump 的暂时不能转换）。
- 要验证码的服务器断网或重启 Pierlink 后，资源概览、端口转发、同步页上有“登录”按钮：登录一次（密码 + 验证码），这些功能就接着用这次登录。
- 某台服务器用内置 SSH 连不上（比如密钥、代理只写在 ~/.ssh/config 里）时，终端里可以一键改用系统 OpenSSH 重试。
- 文件面板传大文件时不拖慢同一台服务器的终端。
- 自动更新：有新版本时在窗口底部提示，一键更新；更新包有数字签名，更新前会先正常关闭同步和终端。

已知限制：内置 SSH 不读 ~/.ssh/config，暂不支持 X11 转发、agent 转发、PuTTY 的 .ppk 密钥、主机证书、Kerberos 登录和代理（ProxyCommand）；需要这些的服务器请在设置里选“系统 OpenSSH”。
