Pierlink 1.2.14

修复终端最下面几行有时显示不出来，全屏程序（Codex 等）的输入框落在看不见的地方。在程序里检查更新即可升级。

- 修复：终端有时会比它实际能显示的多算出几行，Codex 这类把输入框画在最下面的程序，输入框就看不到或只露出一条边。两种情况都修了：终端正在打开的那一瞬间窗格大小变了（标签栏冒出滚动条、窗口刚还原），新的大小没有告诉后面的控制台；终端用的字体比第一次测量晚加载好，之后第一次改窗口大小、或第一次切到启动时恢复出来的标签，行数是按旧的行高算的。

Pierlink 1.2.14 (English)

Fixes the bottom rows of a terminal sometimes not showing, which put the input box of full-screen programs such as Codex out of view. Update inside the app.

- Fixed: A terminal could be given a few more rows than it can show, so programs that draw their input box on the last rows, such as Codex, had it hidden or showing only an edge. Both causes are fixed: the pane changing size at the moment the terminal was opening (the tab bar gaining a scrollbar, the window being restored) without the new size reaching the console behind it; and the terminal font finishing loading after the first measurement, so the first window resize, or the first switch to a tab restored at startup, computed rows from the old line height.
