Pierlink 1.2.14

修复终端里全屏程序（Codex 等）最下面的输入框有时显示不出来。在程序里检查更新即可升级。

- 修复：新开的终端有时比它实际能显示的行数多算了几行，Codex 这类把输入框画在最下面的程序，输入框就落在看不见的地方，只露出一条边。原因是终端正在打开的那一瞬间窗格大小变了（标签栏冒出滚动条、窗口刚还原），新的大小没有告诉后面的控制台。现在终端一打开就把大小对齐。

Pierlink 1.2.14 (English)

Fixes the input box of full-screen programs such as Codex sometimes not showing at the bottom of a terminal. Update inside the app.

- Fixed: A newly opened terminal could be given a few more rows than it can show, so programs that draw their input box on the last rows, such as Codex, had it land out of view with only an edge visible. This happened when the pane changed size at the moment the terminal was opening (the tab bar gaining a scrollbar, the window being restored) and the new size never reached the console behind it. The size is now synced as soon as the terminal opens.
