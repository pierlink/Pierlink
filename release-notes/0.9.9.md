Pierlink 0.9.9

- AI 接入（MCP）用起来更清楚：
  - 第一次打开时先问“你的 AI 装在哪”：装在服务器上还是这台电脑上，点了直接打开对应的入口。入口页顶上有三步（打开入口、添加到 AI 客户端、勾选它能操作的），做完一步打一个勾；服务器上的 AI 排在前面。
  - 写明了“执行命令”和文件夹的关系：勾了“在这台 Windows 上执行命令”，AI 用 PowerShell 能读写整个 Windows 账户，不受授权文件夹限制；文件夹只限制文件工具。
  - 去掉了终端上的“交给 AI”：权限给在入口上，AI 就能在 Windows 上执行命令；需要看得见的终端时 AI 自己开一个，你随时能接管。
  - 连接时不再弹“允许这个 AI 连接吗”。服务器入口可以打开“AI 连上来时先问我”（和别人共用服务器时用）。Pierlink 以管理员身份运行时会提示，本机入口只让同样以管理员身份运行的程序连。
  - 取消“执行命令”或关掉入口时，正在跑的命令一秒左右就停，不用等它跑完。
  - 标题栏的 AI 按钮直接写状态：“AI 正在操作”（带跳动的圆点）或“AI 已连接”，不再显示让人困惑的个数；点开能看到每个 AI 从哪个入口来、最后一次操作在几分钟前。
  - 操作记录里的长内容，鼠标放上去出现的预览框可以移进去，选中一段复制。
- 终端：
  - 快到右边界时打拼音，整个终端不会再往左挪；拼音框贴着右边显示，候选框留在终端里。
  - 在 screen 等程序里断线或点了“断开”，按 Enter 重连后移动鼠标，不会再冒出“35;33;34M”这样的乱码。
  - 新版系统 OpenSSH（10.x，Git for Windows 等自带）第一次连服务器时能正常弹出指纹确认，以前会直接报错。
- 服务器桌面：认得 Ubuntu 26.04、Debian 13 自带的 TigerVNC 1.15，能正常新建和连接桌面。
- 手机：
  - 看终端时底部的四个标签一直在（打字时键盘挡住除外），“只能看”的提示不再挡住它们。在终端里再点“终端”回到列表；切到别的标签再回来时接着看刚才的终端。
  - 手机页面默认跟随电脑的深浅色，终端颜色和电脑上一致；概况页“外观”里可以改成跟随手机、深色或浅色。
  - 打字时点键盘栏或选项按钮，键盘不会收起。
  - 概况页的 AI 一栏写“AI 正在操作 / AI 已连接”，不再显示个数。

Pierlink 0.9.9 (English)

- AI access (MCP) is easier to set up and understand:
  - The first time, it asks where your AI is installed (on a server or on this computer) and turns on the matching entry. Each entry shows three steps (Turn it on, Add it to your AI client, Choose what it can use) that get a check mark as you finish them. Server entries are listed first.
  - The page now says how commands and folders relate: with "Run commands on this Windows computer" checked, the AI can use PowerShell anywhere in your Windows account, and the folder list only limits the file tools.
  - "Hand to AI" is gone from terminals. Granting command access to an entry is enough for the AI to run commands on Windows, and when a visible terminal helps, the AI opens its own one that you can take over at any time.
  - Connecting no longer asks "Allow this AI to connect?". Server entries can turn on "Ask me before an AI can connect" (useful on shared servers). When Pierlink runs as administrator, the MCP page says so and the local entry only accepts programs that also run as administrator.
  - Unchecking command access or turning an entry off stops a running command within about a second.
  - The title-bar AI button shows its state, "AI is working" (with a pulsing dot) or "AI connected", instead of a confusing count. Opening it shows which entry each AI uses and how long ago it last did something.
  - In the activity log, you can move the mouse into the preview of a long entry and select and copy part of it.
- Terminal:
  - Typing pinyin near the right edge no longer shifts the whole terminal to the left. The composition box stays against the right edge and the candidate window stays inside the terminal.
  - After a disconnect inside screen or similar programs, moving the mouse in the reconnected terminal no longer types text like "35;33;34M".
  - The newer system OpenSSH (10.x, shipped with Git for Windows and others) now shows the fingerprint confirmation on a first connection instead of failing.
- Server desktop: recognizes TigerVNC 1.15 from Ubuntu 26.04 and Debian 13, so desktops can be created and connected there.
- Phone:
  - The four tabs at the bottom stay visible while you watch a terminal (except while the keyboard is open), and the view-only notice no longer covers them. Tapping Terminals again goes back to the list, and switching tabs and coming back returns to the terminal you were watching.
  - The phone page follows the PC's dark or light theme by default, so terminal colors match the PC. You can switch it to follow the phone, dark or light under Appearance on the overview page.
  - Tapping the key bar or an option button while typing keeps the keyboard open.
  - The AI section on the overview page shows "AI is working" or "AI connected" instead of a count.
