Pierlink 0.9.7

- 新增代理（设置 → 网络）：不使用、跟随系统，或自定义 HTTP / SOCKS5 代理（不支持带用户名密码的代理），可以测试代理是否可用。连接服务器（内置 SSH 和系统 OpenSSH 的终端、文件、同步、端口转发、资源概览、远程桌面等）、检查和下载更新、下载远程桌面组件都走代理；本机终端自动带上代理环境变量。本机和局域网地址默认不走代理，名单可以改。
- 服务器终端可以粘贴图片：剪贴板里是图片时按 Ctrl+V，图片传到那台服务器的 /tmp（只有你能读），路径粘贴进终端，Claude Code 等会显示成 [Image #1]。本机终端存在本机。7 天前的图片在下次粘贴时自动删除。
- 连接服务器时显示进度：内置 SSH 显示解析 → 连接 → 认证 → 会话四步，带已用的秒数，连不上时提示块上标出停在哪一步；系统 OpenSSH 显示已用的秒数。
- 终端断开后，右下角多了“关闭”和“重新连接”两个按钮，按 Enter 照样能重新连接。重新连接后光标不再看不见。
- 粘贴多行：在 Claude Code 这类程序里粘贴，不再弹“每一行都可能当作命令运行”的确认，直接作为换行的文字进去；在 shell 下，粘贴后会逐行执行的才提醒。
- 在 Claude Code 这类自己画光标的程序里用输入法打中文，拼音不再跑到别的行（本机终端和走系统 OpenSSH 的服务器终端会遇到：Windows 自带的伪终端在光标隐藏时不报告光标位置）。
- AI 接入：先点标签选客户端（没装的也能选），下面是这个客户端的手动添加命令和“一键添加”“移除”两个按钮，点标签不会误添加。新增“移除”，移除后换令牌时也不会再加回去。服务器上的 Codex、Gemini CLI 也有了手动添加的命令。
- 服务器右键菜单里新增“复制 IP”，右侧服务器面板的地址旁边也有复制按钮：只复制 IP（或主机名），不带用户名和端口。
- 新建终端的菜单在服务器很多时不再占满屏幕，超出的部分可以滚动。
- 手机连接：以前选的监听地址现在不在本机的地址里时（换了网络、Tailscale 没连），显示“选择地址…”，不再是空白。

Pierlink 0.9.7 (English)

- New proxy settings (Settings → Network): off, follow the system, or a custom HTTP / SOCKS5 proxy (proxies that need a username and password aren't supported), with a button to test it. Server connections (terminals, files, sync, port forwarding, overview and remote desktop, over built-in SSH and system OpenSSH), update checks and downloads, and the remote desktop component download all use it; local terminals get the proxy environment variables automatically. Local and LAN addresses bypass the proxy by default, and the list can be edited.
- Paste images into server terminals: press Ctrl+V with an image on the clipboard and Pierlink uploads it to /tmp on that server (readable only by you) and pastes the path, which Claude Code and similar tools show as [Image #1]. Local terminals save it on this PC. Images older than 7 days are removed the next time you paste one.
- Connecting to a server now shows its progress: built-in SSH shows four steps (resolve → connect → authenticate → session) with the elapsed seconds and marks the step where a failed connection stopped; system OpenSSH shows the elapsed seconds.
- After a terminal disconnects, Close and Reconnect buttons appear in the bottom-right corner; Enter still reconnects. The cursor no longer stays invisible after reconnecting.
- Pasting several lines into a program such as Claude Code no longer asks for confirmation that each line may run as a command; the text goes in with its line breaks. At a shell prompt you are still asked when each line would run right away.
- Typing Chinese with an input method in programs that draw their own cursor, such as Claude Code, no longer shows the pinyin on another line (this affected local terminals and server terminals using system OpenSSH, because the console host built into Windows does not report the cursor position while the cursor is hidden).
- AI access: pick a client by its tab first (clients that aren't installed can be picked too), then use the manual command or the Add and Remove buttons below; clicking a tab never adds anything. The new Remove also stops Pierlink from adding it back when the token changes. Codex and Gemini CLI on servers now have manual commands too.
- The server context menu has a new Copy IP item, and the server panel has a copy button next to the address: it copies just the IP (or host name), without the user name and port.
- The new-terminal menu no longer fills the screen when you have many servers; it scrolls instead.
- Phone access: when the saved listen address is no longer one of this PC's addresses (a different network, Tailscale disconnected), the list shows "Choose an address…" instead of a blank.
