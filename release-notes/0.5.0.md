Pierlink 0.5.0

AI 接入
- AI 接入（MCP）：Claude Code、Cursor 等 AI 助手可以通过 Pierlink 操作你的 Windows 和服务器——执行命令、打开终端、读写你指定的文件夹、等同步完成。默认关闭，在 设置 → AI 接入 里打开。
- 两种接入方式：AI 在这台电脑上时，把设置页给出的一条命令粘贴到终端执行一次即可；AI 在服务器上时，Pierlink 经已有的 SSH 连接把那台服务器的 127.0.0.1 端口通回这台电脑，这台电脑不用开任何对外端口。
- AI 打开的终端在界面上标着“AI”，你能实时看到它在做什么；你一按键 AI 就先等你，也可以点“接管”。标题栏能看到连着的 AI 和最近的操作，一键“全部停止”。
- 安全：AI 第一次连接要你确认；危险命令（rm -rf、格式化、关机等）和写脚本文件要你确认；密码和验证码永远由你自己输入，不经过 AI；每次操作都记录下来，保存 30 天。

其他改进
- 终端广播输入也认得 Windows 上的危险命令（Remove-Item -Recurse、del /s、format 等），回车前先确认。
- ssh-agent 里密钥很多、超过服务器允许的登录尝试次数时，提示说清原因和改法；后台不再反复登录（以免被服务器的防暴力破解规则封掉 IP），也不会作废你记住的密码。“ssh-agent / 默认密钥”方式会先试和密钥文件对应的那把。
- 系统 OpenSSH 模式下选了“指定私钥”的服务器，现在只用这把钥匙登录，不再先把 ssh-agent 里的钥匙挨个试一遍（和内置 SSH 一样）。如果以前私钥路径没填对、实际靠 agent 里别的钥匙登上，升级后会提示登录失败，把私钥路径改对即可。
- 新开的终端直接获得焦点，打开就能输入，不用先点一下。

内置 SSH 和自动更新（原定 0.4.0 的内容，一起在这一版发布）
- 内置 SSH：连接一台服务器只登录一次，终端、文件面板、同步、端口转发、资源概览共用这次登录；要手机验证码的服务器也能用全部功能。
- 终端更顺：服务器输出直接显示，vim、tmux 的鼠标和按键更准，调窗口大小时内容不乱。
- 服务器设置里新增“连接方式”：内置 SSH（默认）或系统 OpenSSH（按 ~/.ssh/config 连接）。从 ssh config 导入的服务器保持原来的方式，可以在它的设置里一键检查并转换成内置 SSH（地址、用户、密钥一起抄过来；带跳板 ProxyJump 的暂时不能转换）。
- 要验证码的服务器断网或重启 Pierlink 后，资源概览、端口转发、同步页上有“登录”按钮：登录一次（密码 + 验证码），这些功能就接着用这次登录。
- 某台服务器用内置 SSH 连不上（比如密钥、代理只写在 ~/.ssh/config 里）时，终端里可以一键改用系统 OpenSSH 重试。
- 文件面板传大文件时不拖慢同一台服务器的终端。
- 自动更新：有新版本时在窗口底部提示，一键更新；更新包有数字签名，更新前会先正常关闭同步和终端。

已知限制：
- AI 接入：服务器入口的令牌存在那台服务器上，那里的 root 或入侵者能读到，所以只对信任的服务器打开、能操作的目标尽量少勾。AI 只能操作它自己打开的终端，不能操作你开着的终端。
- 内置 SSH：不读 ~/.ssh/config，暂不支持 X11 转发、agent 转发、PuTTY 的 .ppk 密钥、主机证书、Kerberos 登录和代理（ProxyCommand）；需要这些的服务器请在设置里选“系统 OpenSSH”。
