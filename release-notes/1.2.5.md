Pierlink 1.2.5

远程桌面里能用 Ctrl+空格切换远程的输入法了。在程序里检查更新即可升级。

- 修复：远程桌面里按 Ctrl+空格没反应。装了中文输入法的 Windows 会把这个键拿去切换本机输入法，远程收不到；现在远程桌面画面有焦点时，Ctrl+空格交给远程。其他快捷键照常归 Windows。

Pierlink 1.2.5 (English)

Ctrl+Space now switches the input method on the remote desktop. Update inside the app.

- Fixed: Ctrl+Space did nothing in the remote desktop. With a Chinese input method installed, Windows takes this key to switch its own input method, so the remote never got it; while the remote desktop has focus, Ctrl+Space now goes to the remote. Other shortcuts still belong to Windows.
