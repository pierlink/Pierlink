Pierlink 1.2.10

关标签、重启更稳妥：判断终端空闲更准，重启前会先告诉你要关掉什么；要等网络的对话框进行中也能关。在程序里检查更新即可升级。

- 改进：关闭服务器终端时，只有 shell 真的回到提示符才当成空闲直接关；程序输出里偶然出现的标记不会再让它不确认就关。用 exec 开头的命令换了 shell 之后，关闭时改为去服务器查，不再每次都弹确认框。
- 改进：“重启 Pierlink”和退出一样先确认：写明会关掉几个终端会话、还有多少文件没同步完；没有会中断的内容时直接重启。
- 改进：文件权限、专用密钥、撤销本机改动、恢复旧版本、移除同步服务器、删除同步任务、编辑同步任务这些对话框，操作进行中也能关掉，操作在后台照常做完；关掉以后才出的错会显示在窗口底部。
- 改进：用系统 OpenSSH 连的服务器上删除不超过 50 个文件（不含文件夹）时，直接用文件面板已经登录好的连接，没保存密码时不会再多问一次密码。
- 修复：从资源管理器右键菜单打开 Pierlink 后点“重启 Pierlink”，重启后不会再多开一次那个目录。
- 改进：服务器列表的收起按钮和右边工具面板的按钮样式一致；用快捷键收起列表时，焦点回到终端，可以直接打字。

Pierlink 1.2.10 (English)

Closing tabs and restarting are safer: idle detection is more accurate, a restart tells you first what it will close, and dialogs that wait on the network can be closed while they work. Update inside the app.

- Improved: Closing a server terminal treats the shell as idle only once it's really back at its prompt; markers that happen to appear in a program's output no longer let it close without asking. After a command starting with exec replaces the shell, closing checks with the server instead of asking every time.
- Improved: Restart Pierlink now asks first, like quitting does: it says how many terminal sessions will close and how many files haven't finished syncing; with nothing to interrupt, it restarts right away.
- Improved: The dialogs for permissions, dedicated keys, reverting local changes, restoring versions, removing a sync server, deleting a sync task and editing a sync task can now be closed while they work; the work finishes in the background, and an error that comes after you close one shows at the bottom of the window.
- Improved: On servers that connect with system OpenSSH, deleting up to 50 files (no folders) uses the file panel's already signed-in connection, so you aren't asked for the password again when it isn't saved.
- Fixed: After opening Pierlink from the Explorer context menu, Restart Pierlink no longer opens that folder a second time.
- Improved: The server list button matches the tool panel button on the right; hiding the list with a shortcut puts the focus back in the terminal so you can keep typing.
