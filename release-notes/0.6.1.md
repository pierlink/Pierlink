Pierlink 0.6.1

- 换电脑可以迁移了：设置 → 备份和迁移，“导出到文件…”把服务器列表、端口转发、命令片段、应用设置和 MCP 设置存成一个文件，在新电脑上“从文件导入…”。不包含密码和令牌，也不包含同步任务（目录不同，要在新电脑上重新建）。导入时已有的服务器会跳过，新增的 MCP 服务器入口默认关闭，导完列出跳过的和要注意的（比如私钥文件在新电脑上不存在）。
- 文件面板更快：
  - 看过的目录会记住，进出目录先显示记住的列表、后台再更新，不用每次等；刷新按钮只重新读当前目录；
  - 第一次进有很多符号链接的目录也快了（链接的属性一批一起查，不再一个个问）。
- MCP 服务器入口的一键添加会先检测服务器上装了 Claude Code、Codex 中的哪些，没装的按钮显示“未安装”。
- 同一个目录可以同步到多台服务器：同步页任务详情里点“添加服务器”，选服务器和服务器上的目录（本机目录、排除规则和设置沿用这个任务的），检查目录、看过首次同步预览后添加；每台服务器旁边的“×”可以单独移除（至少留一台，两边文件都保留）。
- 服务器概况：
  - 分屏后窗格变窄也能显示（窄了自动排成两行）；
  - 内存、交换、GPU 下面显示已用/总量（GPU 是显存，多张卡加起来）；
  - 顶部去掉了负载，运行时间和系统名一行显示完整。
- MCP：
  - 一键添加会检测这台电脑上装了哪些客户端（Claude Code、Codex、Cursor），没装的按钮显示“未安装”；
  - 服务器入口也能一键添加到服务器上的 Codex（写进 ~/.codex/config.toml，原有内容不动）；
  - “换令牌”有说明和结果提示；
  - 收回交给 AI 的终端时，正在等你回答的确认框立即关掉；
  - “交给 AI”没有能接手的入口时，说明文字能看全。
- 应用里的更新说明只显示当前界面语言的那一段。

Pierlink 0.6.1 (English)

- Moving to a new PC: Settings → Backup & transfer. "Export…" saves your servers, port forwards, snippets, app settings and MCP settings to one file; "Import…" on the new PC brings them in. Passwords and tokens are not included, and neither are sync tasks (folders differ, so create them again on the new PC). Existing servers are skipped, new MCP server entries start off, and afterwards you get a list of what was skipped or needs attention (for example, a private key file that doesn't exist on the new PC).
- Faster file panel:
  - Folders you've visited are remembered: going in and out shows the remembered list right away and updates it in the background; the refresh button re-reads only the current folder;
  - First visits to folders with many symlinks are faster too (symlink details are looked up in batches instead of one by one).
- One-click setup for MCP server entries first checks which of Claude Code and Codex are installed on the server; missing ones show "not installed".
- Sync one folder to several servers: in a task's details on the Sync page, click "Add server", choose the server and a folder on it (the local folder, exclusion rules and settings come from the task), and add it after the folder check and first-sync preview; the "×" next to each server removes just that one (at least one must stay; files on both sides are kept).
- Server overview:
  - Also shown in narrow split panes (switches to two rows when narrow);
  - Memory, swap and GPU show used/total underneath (GPU is video memory, summed across cards);
  - Load removed from the top line, so uptime and OS name fit on one line.
- MCP:
  - One-click setup detects which clients are installed on this PC (Claude Code, Codex, Cursor); missing ones show "not installed";
  - Server entries can also be added to Codex on the server in one click (written to ~/.codex/config.toml, leaving the rest untouched);
  - "Rotate token" now explains what it does and shows the result;
  - Taking back a terminal handed to AI closes any confirmation still waiting for your answer;
  - When no entry can take a terminal, the full explanation is now readable.
- In-app release notes show only the section in your interface language.
