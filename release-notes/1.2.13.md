Pierlink 1.2.13

标签可以改名；输入法不再跑到屏幕左上角、打的字不再重复；终端最下面一行不再被切掉一截；文件面板点进目录不用等。在程序里检查更新即可升级。

- 新增：标签可以改名。右键标签选“重命名”（或双击标签、按 F2）；清空就恢复自动的名字。
- 修复：点过或拖过窗口边框（改窗口大小）之后，输入法的拼音会跑到屏幕左上角的小框里，终端里打出来的字还会重复；切到别的窗口再回来才恢复。现在输入法一直跟着输入框，字也只上屏一遍。
- 修复：终端窗格的高度凑巧时，最下面一行会被下边缘切掉一截（全屏的命令行程序里最明显）。
- 改进：文件面板点进目录马上就进去，列表读到了再填上，不用先等它读完；连着点几个目录只显示最后点的那个。

Pierlink 1.2.13 (English)

Tabs can be renamed; the input method no longer jumps to the top-left corner of the screen or doubles what you type; the bottom line of terminals is no longer cut off; and the file panel enters folders right away. Update inside the app.

- New: Tabs can be renamed. Right-click a tab and choose Rename (or double-click it, or press F2); clear the name to go back to the automatic one.
- Fixed: After clicking or dragging the window border (resizing the window), the input method composed in a small box at the top-left corner of the screen and text typed into a terminal came out twice, until you switched to another window and back. The input method now stays with the input box and text is entered once.
- Fixed: At certain pane heights the last terminal line was partly cut off by the bottom edge, most visible in full-screen command-line programs.
- Improved: The file panel enters a folder as soon as you open it and fills in the list when it arrives, instead of waiting for it to load; opening several folders in a row only shows the last one.
