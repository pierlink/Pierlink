Pierlink 0.7.1

- 导出服务器：服务器列表上方的“导入 / 导出服务器”→“导出服务器…”，勾选要给别人的服务器，存成一个文件（不含密码和备注；用到的跳板机自动带上；从 ssh config 导入的服务器不在列表里）。对方在“导入 / 导出服务器”→“从文件导入…”里导入。右键单台服务器也能导出。
- 概况卡片右上角改成“连接时显示”开关：关掉后，连接服务器时不再自动显示概况；这次要看时点终端上方的概况按钮。
- 界面文字精简：去掉多余的解释。
- 概况卡片改用不透明底色，终端文字不再透出来。
- 许可证改为 FSL-1.1-ALv2：个人和公司都可以免费使用、阅读和修改源码，不能拿它做竞品；每个版本满两年后自动改为 Apache 2.0。安装目录 licenses 文件夹里附带许可证全文。
- 安装程序开始时可以选择中文或英文（默认跟随系统语言，之后更新不再询问），并显示许可证。
- 第三方组件许可证补全：补上 LibreSSL（随 OpenSSH 附带的 libcrypto.dll）和 12 个缺原文的组件的许可证全文，并写明 MPL-2.0 组件的源代码地址。

Pierlink 0.7.1 (English)

- Export servers: Import / export servers → Export servers… above the server list. Pick the servers to share and save them to a file (no passwords or notes; jump hosts they use are included; servers imported from ssh config aren't listed). Others import it via Import / export servers → Import from file… You can also export a single server from its right-click menu.
- The overview card's top-right control is now a "Show on connect" switch: turn it off and the overview no longer opens when you connect; use the overview button above the terminal to show it.
- Shorter UI text throughout.
- The overview card now has an opaque background, so terminal text no longer shows through.
- Pierlink is now licensed under FSL-1.1-ALv2: free for individuals and companies to use, read and modify, but not to build a competing product; each version becomes Apache 2.0 two years after release. The full text is in the licenses folder of the install directory.
- The installer now starts with a language choice, English or Chinese (defaults to the system language; updates don't ask again), and shows the license.
- Third-party notices completed: added the license texts for LibreSSL (libcrypto.dll shipped with OpenSSH) and 12 components that lacked them, plus source links for MPL-2.0 components.
