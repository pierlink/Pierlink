Pierlink 1.2.11

常驻托盘、几天不重启也能收到新版本；可以开机自动启动；Win+V 剪贴板历史能粘进服务器终端了；设置里可以直接提交问题。在程序里检查更新即可升级。

- 改进：除了启动后检查一次，之后每 6 小时自动检查一次更新。有新版本时在窗口右下角出一张小卡片，可以选“下载更新”或“稍后”；点了“稍后”，这个版本一天内不再提示，出了更新的版本马上提示。
- 修复：在服务器终端里（比如 Claude Code）用 Windows 剪贴板历史（Win+V）选一条粘贴时，内容粘不进去。
- 新增：设置 → 关于里有“提交问题”，点了打开 GitHub 的新建问题页面，版本号已经填好。
- 新增：设置里可以打开“开机自动启动”（默认关）：登录 Windows 后 Pierlink 在托盘里启动，不弹出窗口。

Pierlink 1.2.11 (English)

Even if Pierlink stays in the tray for days, you'll hear about new versions; it can start with Windows; Win+V clipboard history pastes into server terminals; and you can report a problem straight from Settings. Update inside the app.

- Improved: Besides the check after start-up, Pierlink checks for updates every 6 hours. A new version shows up as a small card in the bottom-right corner of the window, where you choose Download update or Later; after Later, that version stays quiet for a day, while a newer one shows up right away.
- Fixed: Picking an item from Windows clipboard history (Win+V) didn't paste into server terminals such as Claude Code.
- New: Settings > About has "Report an issue", which opens a new GitHub issue with your version already filled in.
- New: Settings has "Start with Windows" (off by default): after you sign in, Pierlink starts in the tray without opening a window.
