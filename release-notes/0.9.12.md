Pierlink 0.9.12

- 自动更新：
  - 先下载、后安装：点“下载更新”只下载并核对签名，下好后你点“安装更新”才会关闭 Pierlink 并安装；选“稍后”的话，下次点提示条上的“安装更新”直接装，不用再下载（重启后也一样）。
  - 下载好以后又出了更新的版本：检查更新时会删掉旧的安装包，让你下载最新的，不会装上旧的那个。
  - 下载时网络断了，以前进度会一直停着；这时再点一次会多开一个下载，网络恢复后两个一起走，进度条来回跳。现在同一时间只下载一个；30 秒收不到数据就停下并提示网络中断，点“重试”接着下。

Pierlink 0.9.12 (English)

- Updates:
  - Download first, install when you say so: Download update only downloads and checks the signature; Pierlink closes and installs only after you click Install update. If you pick Later, Install update on the bar installs right away next time without downloading again (also after a restart).
  - If a newer version comes out after you downloaded one, checking for updates removes the old package and offers the newest, so the old one is never installed.
  - If the network dropped while downloading, the progress used to stop for good, and clicking again started a second download, so the progress bar jumped back and forth once the network came back. Now only one download runs at a time; after 30 seconds without data it stops and says the network dropped; click Retry to continue.
