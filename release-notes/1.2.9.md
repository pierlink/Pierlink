Pierlink 1.2.9

关服务器标签不用再等；删大文件夹不再卡住界面；服务器列表可以收起；安装桌面时可以顺便装上 Chrome；系统网页组件出问题时一键重启就好。在程序里检查更新即可升级。

- 改进：关闭服务器终端不再先等服务器回话。服务器上的 bash（4.4 及以上）和 zsh 会随时告诉 Pierlink 终端是在等输入还是在跑命令：在等输入就直接关，在跑程序马上问你要不要关。其他情况仍会去服务器查一下；用内置 SSH 的服务器，鼠标移到关闭按钮上就开始查，点下去时一般已经查完。
- 新增：安装桌面时可以勾选“同时安装 Chrome 浏览器”。下载和安装 Chrome 的命令一直显示，也可以复制下来自己运行。连上桌面后，工具栏的“浏览器”按钮里写着怎么打开 Chrome（在桌面的终端里运行 google-chrome），还没装的可以直接在下面的终端里装。
- 修复：文件面板删除文件很多的文件夹时，确认框一直挡着、关不掉也点不了别的地方。现在点了删除确认框马上关掉，右下角的小窗写着正在删哪个文件，点 × 可以停下；也可以选“快速删除（rm -rf）”在服务器上一次删完。
- 新增：工作区左边的服务器列表可以收起（标签栏最左边的按钮），给终端腾出地方；开关记在这台电脑上。
- 改进：系统的网页组件（WebView2）断开、打不开桌面独立窗口时，会说明原因并给出“重启 Pierlink”按钮，不再只显示一串错误代码。

Pierlink 1.2.9 (English)

Closing server tabs no longer waits; deleting big folders no longer freezes the window; the server list can be hidden; desktop install can add Chrome; when Windows' web component breaks, one click restarts Pierlink. Update inside the app.

- Improved: Closing a server terminal no longer waits on the server first. bash (4.4 or later) and zsh on the server now keep Pierlink posted on whether the terminal is waiting for input or running a command: an idle one closes right away, and a running program gets the confirmation at once. Other shells still get a quick check on the server; on servers that use the built-in SSH, the check starts as soon as the pointer reaches the close button, so it's usually done by the time you click.
- New: Desktop install can also install Chrome (tick "Also install Chrome"). The commands that download and install Chrome are always shown, so you can copy and run them yourself. Once connected, the Browser button on the desktop toolbar tells you how to open Chrome (run google-chrome in the desktop's terminal) and can install it in a terminal below.
- Fixed: Deleting a folder with lots of files in the file panel left the dialog stuck on screen, and nothing else could be clicked or closed. The dialog now closes right away, a small window in the corner shows which file is being deleted, and × stops it; or pick "Fast delete (rm -rf)" to remove everything at once on the server.
- New: The server list on the left of the workspace can be hidden with the button at the left end of the tab bar, giving terminals more room; the choice is remembered on this computer.
- Improved: When Windows' web component (WebView2) disconnects and the desktop window can't open, Pierlink says why and offers Restart Pierlink instead of an error code.
