Pierlink 0.6.0

- MCP 单独成页（顶部导航“同步”后面），原来设置里的“AI 接入”移到这里：
  - 左边是入口列表（本机、各台服务器），右边是选中入口的命令、连着的 AI、审批方式和权限；可以一次添加多台服务器的入口；
  - 操作记录单独一页，可以按入口筛选；列宽可以拖动（会记住），鼠标停在单元格上显示完整内容；“打开日志文件夹”；
  - 一键添加：本机入口一键加进 Claude Code、Codex 或 Cursor；服务器入口一键在那台服务器上加进 Claude Code，以后换令牌会自动重新添加；
  - 文件夹权限可以点“选择文件夹…”从 Windows 里选。
- 终端可以交给 AI：窗格标题栏点 AI 按钮，把开着的终端交给某个入口的 AI（比如服务器上的 Claude 操作 Windows 上的终端，Windows 上不用装 Claude）；随时点“收回”。AI 能列出你开着的终端（名字、类型、哪台服务器），交出后才能看到当前目录和内容；你打过字后，AI 下一次回车要你确认。
- 服务器概况常驻在服务器终端右上角：CPU、内存、交换、GPU，每个挂载点的磁盘，网速可以选网卡；点按钮隐藏（隐藏时采样不停，再打开马上有数）；同一台服务器开多个终端只采一份。右侧工具面板只留端口转发和命令片段。
- 同步：
  - “旧版本”对话框里显示本机和各服务器回收站占了多少，可以立即清空；
  - 最近事件标出是本机还是哪台服务器改的；事件保留 90 天（每个任务最多 2 万条），可以“加载更早的事件”，更早的事件带日期；
  - 新建任务时本机目录可以点“选择文件夹…”；
  - “在 VS Code 打开”同步目录（也能选 Cursor 等其他编辑器，每个任务记住上次用的）；
  - 冲突可以“对比两个版本”：文本文件左右并排显示不同的行，看完直接选保留哪个；
  - 可以打开本机的 Syncthing 管理页（应用内窗口，自动登录）。关掉后，如果在里面改了 Pierlink 管的设置：安全相关的自动恢复，同步任务的设置逐项让你选“采用新值”或“恢复”。服务器上的管理页请用端口转发自己打开；
  - 同一个目录同步到多台服务器排在 0.6.1，按钮先藏起来了。
- 界面不再跳动：检查更新的结果、终端广播的状态、断网和新版本提示、端口转发和文件面板的出错提示都放在固定位置；对话框靠上显示，内容变多时只往下长。
- Git Bash 空闲时关闭不再误提示“有程序在运行”。

Pierlink 0.6.0 (English)

- MCP now has its own page (top bar, after Sync); the old "AI access" section in Settings moved here:
  - Entries on the left (this PC and each server), and on the right the selected entry's commands, connected AIs, approval mode and permissions; add several server entries at once;
  - The activity log has its own page with an entry filter; column widths can be dragged (and are remembered); hover a cell to see its full content; "Open log folder";
  - One-click setup: add the local entry to Claude Code, Codex or Cursor; add a server entry to Claude Code on that server in one click, re-added automatically after a token change;
  - Folder permissions can be picked from Windows with "Choose folder…".
- Hand a terminal to AI: click the AI button in a pane's title bar to hand an open terminal to the AI of an entry (for example, Claude on a server can work in a Windows terminal, without installing Claude on Windows); click "Take back" any time. AI can list your open terminals (name, type, server); it sees the current folder and content only after you hand one over. The AI's first Enter after a handover, or after you type, needs your confirmation.
- The server overview is pinned to the top-right of server terminals: CPU, memory, swap, GPU, disk usage per mount point, network speed per interface you choose; hide it with a button (sampling continues, so numbers are instant when shown again); several terminals on the same server share one sampler. The right-hand tool panel now only has port forwarding and snippets.
- Sync:
  - The "Old versions" dialog shows how much the trash uses on this PC and each server, and can clear it now;
  - Recent events show whether this PC or which server made the change; events are kept for 90 days (up to 20,000 per task) with "Load earlier events", and older events show the date;
  - "Choose folder…" for the local folder when creating a task;
  - "Open in VS Code" for the synced folder (or Cursor and other editors; each task remembers the last one);
  - Conflicts can be compared: text files show differing lines side by side, then choose which to keep;
  - Open this PC's Syncthing admin page (in-app window, signed in automatically). After closing it, if you changed settings Pierlink manages: security-related ones are restored automatically, and each sync task setting asks you to adopt the new value or restore it. For a server's admin page, open it yourself through port forwarding;
  - Syncing one folder to several servers is planned for 0.6.1; its button is hidden for now.
- No more layout jumps: update-check results, terminal broadcast status, network and new-version notices, and port-forwarding and file-panel errors all have fixed places; dialogs sit near the top and only grow downward.
- Closing an idle Git Bash no longer warns that a program is running.
