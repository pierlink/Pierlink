Pierlink 1.2.16

连接服务器只用内置 SSH，不再有“系统 OpenSSH”这个选项。在程序里检查更新即可升级。

- **只用内置 SSH**：添加、编辑服务器时不再有“连接方式”一栏；升级后，原来在应用里添加、选了系统 OpenSSH 的服务器会自动改成内置 SSH；快速连接（直接输入“用户@主机”）也走内置 SSH；终端连不上时不再提供“改用系统 OpenSSH 重试”。内置 SSH 每台服务器只登录一次，终端、文件、端口转发、同步、AI 接入共用这一条连接。
- 内置 SSH 不支持这些登录方式：ProxyCommand、证书登录、硬件密钥（FIDO、PKCS#11）、Kerberos（GSSAPI）、Pageant。从 `~/.ssh/config` 导入的服务器这一版仍按原配置连接，可以在它的设置里“改用内置 SSH”；下一版起导入的服务器也只走内置 SSH。
- 没填用户名的服务器，登录时用这台电脑当前的用户名。
- 修复：服务器上的 screen 里，程序设了中文标题时，重新接回会话后屏幕上多出几个乱码。
- 修复：在 tmux 里，手机输入前的核对（危险命令确认、终端是不是在等密码）读到的是 tmux 的状态栏；AI 往终端发文字前“是不是在等密码”的判断同样。现在读光标所在的那一行。
- 修复：服务器概况那条连接断开后只隔一秒就重新登录，网络时通时断时登录过于频繁。
- 修复：英文界面的操作记录里，改文件的次数说明是中文。
- 修复：文件面板铺满窗格时，点窗格标题栏的“连接/断开”、发命令片段后，键盘落到被盖住的终端上。

Pierlink 1.2.16 (English)

Servers are connected with the built-in SSH only; the "System OpenSSH" option is gone. Update inside the app.

- **Built-in SSH only**: the add and edit server dialogs no longer have a "Connection" field. After updating, servers you added in the app that were set to System OpenSSH switch to the built-in SSH automatically. Quick connect (typing "user@host") uses the built-in SSH too, and a failed connection no longer offers "Retry with System OpenSSH". The built-in SSH logs in once per server; terminals, files, port forwarding, sync and AI access share that one connection.
- The built-in SSH does not support these ways of logging in: ProxyCommand, certificate authentication, hardware keys (FIDO, PKCS#11), Kerberos (GSSAPI) and Pageant. Servers imported from `~/.ssh/config` still connect with their original configuration in this version, and can be switched in their settings ("Use built-in SSH"); from the next version imported servers will use the built-in SSH as well.
- A server without a user name logs in with this PC's current user name.
- Fixed: inside screen on a server, a program setting a non-ASCII title left a few garbage characters on the screen after re-attaching.
- Fixed: inside tmux, the checks before phone input (risky-command confirmation, whether the terminal is waiting for a password) read tmux's status line; the same check before AI types into a terminal did too. They now read the row the cursor is on.
- Fixed: the server overview connection logged in again one second after every drop, which was too frequent on a flaky network.
- Fixed: in the English UI, the replacement count of file edits in the activity log was in Chinese.
- Fixed: with the file panel covering the pane, the pane's Connect/Disconnect button and command snippets moved the keyboard to the covered terminal.
