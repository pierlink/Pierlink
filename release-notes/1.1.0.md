Pierlink 1.1.0

新增快捷键，并修了第一次添加服务器入口时 AI 连不上、WSL 里新建的 XFCE 桌面起不来的问题。在程序里检查更新即可升级。

- 快捷键：新建终端标签 Ctrl+Shift+T、快速连接 Ctrl+Shift+N、关闭当前窗格 Ctrl+Shift+W、切换标签 Ctrl+Tab / Ctrl+Shift+Tab、左右和上下分屏 Ctrl+Shift+R / Ctrl+Shift+D、广播输入 Ctrl+Shift+B、文件栏 Ctrl+Shift+E、概况 Ctrl+Shift+O、工具面板 Ctrl+Shift+P、命令片段 Ctrl+Shift+S、搜索服务器 Ctrl+Shift+L、设置 Ctrl+,、终端字号 Ctrl+= / Ctrl+- / Ctrl+0。开着中文输入法也能用。
- 在“设置 → 快捷键”里可以改、清空或恢复默认，也可以给切换页面设快捷键；和别的快捷键或终端固定的复制、粘贴、换行冲突时直接提示。
- 修复：第一次添加服务器入口后，服务器上的 AI 有时连不上（401），要关掉入口再打开或重启 Pierlink 才好。
- 修复：在 WSL 里，或在同一个用户正登录着 Wayland 桌面的机器上，新建的 XFCE 桌面起不来。

Pierlink 1.1.0 (English)

Adds keyboard shortcuts and fixes an AI on the server failing to connect right after its server entry was first added, and new XFCE desktops not starting in WSL. Update inside the app.

- Shortcuts: new terminal tab Ctrl+Shift+T, quick connect Ctrl+Shift+N, close pane Ctrl+Shift+W, switch tabs Ctrl+Tab / Ctrl+Shift+Tab, split right and down Ctrl+Shift+R / Ctrl+Shift+D, broadcast input Ctrl+Shift+B, files Ctrl+Shift+E, overview Ctrl+Shift+O, tool panel Ctrl+Shift+P, snippets Ctrl+Shift+S, search servers Ctrl+Shift+L, settings Ctrl+, and terminal font size Ctrl+= / Ctrl+- / Ctrl+0. They work with a Chinese IME on.
- Change, clear or reset any of them in Settings > Shortcuts, and add keys for switching pages; a key already used by another shortcut or by the terminal's copy, paste and new line is refused with the reason.
- Fixed: after a server entry was first added, the AI on that server was sometimes refused (401) until the entry was turned off and on or Pierlink restarted.
- Fixed: a new XFCE desktop did not start in WSL, or on a machine where the same user was logged in to a Wayland desktop.
