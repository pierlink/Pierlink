Pierlink 0.9.10

- 服务器列表：
  - 每台服务器的地址右边多了一个复制按钮，点一下复制 IP，不用再右键。
  - 列表顶部新加一个小眼睛：点了以后侧栏、终端标签、右侧面板里的 IP 都显示成圆点，截图时不会不小心露出来；这时点复制拿到的仍是真实 IP。再点一次恢复显示。
- 终端：
  - 断开、断网或进程退出后，“关闭标签”和“重新连接”改成显示在终端正中间的卡片上（和连接时的卡片同一个位置），断网时卡片是黄色边框。按 Enter 照样重新连接。
  - 点插头断开时不再弹“终端会话不存在或已关闭”。
  - 密码不对时，连接卡片直接换成“登录失败”，中间不再先露出一个空白终端。
  - 标签多到放不下时，鼠标放在标签上滚动滚轮就能左右滚动标签。
  - 拼音打到最右边时，组字框往右伸出，不再往左盖住刚打的字。
  - 下划线光标加粗、加宽了一点。
  - tmux、vim 这类全屏程序里右键也弹出菜单；服务器终端的右键菜单里能关掉这台服务器的命令预测。
  - 程序响铃时（比如 Codex 等你确认或回答），你没在看的那个标签上出现一个闪动的小点；Pierlink 在后台时任务栏按钮会闪。
  - GNU screen 里的 Claude Code 粘贴多行不再弹确认，也不会被一行一行提交。
- 文件：
  - 可以从资源管理器直接把文件拖到服务器的文件栏上传，也可以把服务器文件栏里的文件拖到资源管理器或桌面下载（松手后先下载，会显示进度，下完放到你松手的地方）；服务器文件的右键菜单多了“下载到…”。
  - 设置 → 文件传输 新加“同名文件直接覆盖”（默认关）：打开后拖动传输遇到同名文件不再询问。
- AI 接入（MCP）：
  - 确认框必须点按钮才算回答，点到框外或按 Esc 不再当成拒绝；Pierlink 在后台时任务栏按钮闪烁，窗口标题显示有几条在等你确认。
  - 操作记录在重启、更新后还在（显示最近 200 条）。
  - 服务器上的端口被占用时，说明是谁占着（比如另一台电脑上的 Pierlink、没断干净的旧连接），并可以一键换到空闲端口。
  - 改端口要点“应用”，下面显示改好了没有；换端口或换令牌后，一键添加过的客户端会自动更新，页面上提示重启它们。
  - 每个客户端下面写着加好了没有（地址、令牌是不是现在的），加过的按钮写“重新添加”；页面记住你上次选的入口和客户端。
- 服务器桌面：
  - 修好了在 Ubuntu 22.04 等系统上新建桌面一直失败的问题。
  - 新建桌面的卡片上多了一个问号，点开是要装什么、怎么手动装（也可以发给 AI 让它装）；装失败时直接给出这台服务器的安装命令。
  - 在远程的文件管理器里复制文件再粘贴，不会再变成一段路径文字。
- 手机：打开跑着 Claude Code 的终端时，输入框和底部四个标签不再重叠。
- 点“添加服务器”等按钮时，对话框和变暗的背景一起出现，不会先变暗一会儿才弹出框。

Pierlink 0.9.10 (English)

- Server list:
  - Each server now has a copy button next to its address that copies the IP in one click, without the right-click menu.
  - A new eye button at the top of the list shows every IP as dots in the sidebar, terminal tabs and side panel, so screenshots don't reveal them by accident. The copy button still copies the real IP. Click the eye again to show them.
- Terminal:
  - After you disconnect, the connection drops or the process exits, Close tab and Reconnect now appear on a card in the middle of the terminal (where the connecting card shows). The card has a yellow border when the connection dropped. Enter still reconnects.
  - Disconnecting with the plug button no longer shows "The terminal session doesn't exist or was closed".
  - A wrong password now turns the connecting card straight into "Login failed", without flashing an empty terminal first.
  - When there are more tabs than fit, scrolling the mouse wheel over the tabs moves them left and right.
  - Typing with an IME at the right edge, the composition now grows to the right instead of covering what you just typed.
  - The underline cursor is a little thicker and wider.
  - Right-click shows the menu inside full-screen programs such as tmux and vim too, and the menu in a server terminal can turn off command prediction for that server.
  - When a program rings the bell (for example Codex waiting for your approval or answer), the tab you aren't looking at gets a pulsing dot, and the taskbar button flashes when Pierlink is in the background.
  - Pasting several lines into Claude Code inside GNU screen no longer asks for confirmation and isn't submitted line by line.
- Files:
  - Drag files from File Explorer onto a server's file panel to upload them, or drag files from a server's file panel to File Explorer or the desktop to download them (the download starts when you let go, with a progress window, and the files land where you dropped them). Server files' right-click menu also has Download to….
  - Settings > File transfer > Overwrite files with the same name (off by default): drag transfers stop asking about files with the same name.
- AI access (MCP):
  - Confirmations need a button click: clicking outside the dialog or pressing Esc no longer counts as Deny. When Pierlink is in the background the taskbar button flashes and the window title shows how many are waiting.
  - The activity list survives restarts and updates (the latest 200 entries).
  - When the port on the server is taken, the page says who has it (for example Pierlink on another PC, or an earlier connection that didn't close cleanly) and offers a free port in one click.
  - Changing the port now uses an Apply button and shows whether it worked. After changing the port or the token, one-click setups update themselves and the page reminds you to restart them.
  - Each client shows whether it's set up with the current address and token, and Add becomes Re-add once it is. The page remembers the entry and client you picked.
- Server desktop:
  - Fixed creating a desktop failing every time on Ubuntu 22.04 and similar systems.
  - A question mark on the new-desktop card explains what to install and how to do it yourself (or hand it to an AI). If installing fails, the card shows the install command for that server.
  - Copying a file in the remote file manager and pasting it no longer turns it into a line of text.
- Phone: with Claude Code running in a terminal, the input box no longer overlaps the four tabs at the bottom.
- Dialogs such as Add server now appear together with the dimmed background instead of a moment after it.
